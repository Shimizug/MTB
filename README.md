# 目標・タスク管理アプリ「My Guide to Supremacy」

## 概要

本アプリは、ユーザーが設定した目標と、その達成に必要なタスクを管理するWebアプリケーションです。
単純なタスク管理だけではなく、目標達成までの行動を整理し、継続しやすくすることを目的としています。
目標を設定した際には、AIが目標達成に必要なタスクを提案することもかのうです。
また、目標達成を妨げる行動を「アンチタスク」として登録し、あわせて管理します。
タスク達成時には、自分へのご褒美を設定、アンチタスク実施時には罰を設定できます。

## アプリの目的

本アプリの目的は、目標、タスク、目標達成を妨げる行動、達成時のご褒美を一元管理し、ユーザーが目標に向けて行動しやすい環境を作ることです。
主に以下の課題を解決します。

- 目標を立てても、何から始めればよいか分からない
- 目標が大きすぎて具体的な行動に落とし込めない
- タスクを登録しても継続できない
- 目標達成を妨げている行動を把握できない
- タスクを達成しても達成感を得にくい

## 主な機能

### 目標管理

目標を登録し、期限、優先度、進捗状況などを管理します。
管理項目の例：

- 目標名
- 目標の説明
- 達成予定日
- 達成条件
- 優先度
- ステータス
- 進捗率

### タスク管理

目標達成に必要なタスクを登録し、実行状況を管理します。
管理項目の例：

- タスク名
- 関連する目標
- タスクの説明
- 期限
- 優先度
- ステータス
- 予定作業時間
- 実際の作業時間

### タスク提案

目標を設定した際に、AIが目標達成に必要なタスクを提案します。
例：

```text
目標：
C#（.NET 10）でWebアプリを完成させる
提案されるタスク：
・必要な機能を整理する
・ASP.NET Coreの開発環境を構築する
・データベースを設計する
・目標登録機能を作成する
・タスク登録機能を作成する
・テストを作成する
・Azureへ公開する
```

AIが提案したタスクは、ユーザーが内容を確認した後に登録します。AIが自動的にタスクを追加するのではなく、ユーザーの承認を必要とする設計にします。

### アンチタスク管理

目標達成を妨げる行動を「アンチタスク」として登録します。
アンチタスクの例：

- 作業中にSNSを見る
- 寝る前に長時間動画を見る
- 優先度の低い作業を先に始める
- 完璧を求めすぎて作業を始めない
- 予定を立てずに作業する
  管理項目の例：
- アンチタスク名
- 関連する目標
- 発生しやすい時間帯
- 発生回数
- 対策
- 改善状況
  アンチタスクを記録することで、目標達成を妨げている行動を可視化し、改善方法を考えられるようにします。

### ご褒美・罰管理

タスクや目標を達成した際に受け取るご褒美・罰を設定します。
ご褒美の例：

- 好きなお菓子を食べる
- ゲームを30分する
- 欲しかった商品を購入する
- 好きな動画や映画を見る
- 休日に外出する
  管理項目の例：
- ご褒美名
- 対象となる目標またはタスク
- 達成条件
- 必要ポイント
- 使用済みかどうか

罰の例

- 腹筋30回
- お小遣いを募金する

### AI相談

登録した目標、タスク、アンチタスク、進捗状況をもとに、AIへ相談できます。
相談例：

- 今日何を優先すべきか
- 目標達成が遅れている原因
- タスクをさらに細かく分ける方法
- アンチタスクを減らす方法
- 来週の計画の立て方
- 達成状況の振り返り
  AIには、ユーザーが入力した相談内容だけでなく、以下の情報を渡します。
- 現在の目標
- 未完了タスク
- 期限切れタスク
- 最近完了したタスク
- 登録されたアンチタスク
- タスクの実行時間
- 目標の進捗率

## 対応環境

本アプリは、PCおよびスマートフォンのブラウザから利用できるレスポンシブWebアプリケーションとして開発します。

## 開発環境

### ホスト環境

- OS：Windows
- エディター：Visual Studio Code
- バージョン管理：Git
- ソースコード管理：GitHub

### コンテナ環境

- Podman
- Podman Compose
- Linuxコンテナ
  Windows上でPodmanを使用し、Linuxコンテナ内でアプリケーションを実行します。

### バックエンド

- C#
- .NET 10
- ASP.NET Core Web API
- Entity Framework Core
- xUnit

### フロントエンド

- Vue.js
- TypeScript
- Vite

### データベース

- PostgreSQL
  PostgreSQLには、ユーザー、目標、タスク、アンチタスク、ご褒美、AI相談履歴などの主要データを保存します。

### AI

- Azure OpenAI
  主な利用目的：
- 目標からタスクを提案
- タスクを具体化
- 優先順位を提案
- アンチタスクへの対策を提案
- 計画を見直す
- 週次振り返りを作成

### クラウド

- Microsoft Azure
- Azure Container Apps
- Azure Database for PostgreSQL
- Azure Key Vault
- Azure Monitor
- Azure Blob Storage
- Azure Container Registry

### インフラ管理

- Terraform
  Azure上のインフラ環境をTerraformでコード化し、同じ環境を再構築できるようにします。

### CI/CD

- GitHub Actions
  自動化する処理：
- .NETのビルドとテスト
- TypeScriptの型チェック
- Vue.jsのビルド
- コンテナイメージの作成
- Azureへのデプロイ
- Terraformの構文チェック

### 開発支援AI

- ChatGPT Plus
- Codex
- GitHub Copilot Free
- takt
  役割：
- ChatGPT：要件整理、設計、学習、エラーの確認
- Codex：機能単位の実装、修正、テスト
- GitHub Copilot：VS Code上でのコード補完
- takt：AIエージェントを利用した開発工程の自動化
